# 수요일 생활경제 기준

기준일: 2026-10-07 KST · 모드: `life-economics-v1` · 적용 시작: 2026-10-12 KST (`weekly-2221-v1`)

## 범위와 실제 입력

수요일은 `category="investment"`, 네이버 카테고리 7 안에서 **소유자의 실제 생활경제 질문**에 답합니다. 환율·금리·생활 금융의 조건, 비용, 확인 방법을 다룹니다. 종목과의 연결이나 KIS 정책 심사 통과를 전제하지 않습니다. 금요일의 [WEEKLY_POLICY](WEEKLY_POLICY.md)는 별도 경로이며 최근 5일·원본 최소 14점 등 기존 문턱을 유지합니다.

편성 승인은 주제 선택이 아닙니다. 엔화·육아 관련 생활경제·K-GX 예시는 미선정이며 이 문서나 예시만으로 새 후보를 등록하지 않습니다. 실제 질문·자료가 없으면 `PLANNED_INPUT_REQUIRED`로 보류하며 트렌드·오래된 큐·금요일 KIS 정책으로 대신 채우지 않습니다.

## 입력 계약과 원문 확인

실제 비공개 입력 등록은 문서·코드 변경과 별개입니다. 기존 입력 큐에 고유 `id`와 실제 소유자 질문을 등록하되 설명용 예시는 `enabled=false`로 유지합니다.

| 필드 | 기준 |
|---|---|
| `category` / `investment_mode` | 정확히 `investment` / `life-economics-v1` |
| `question` | 실제 소유자 질문, 필수 |
| `context` | 선택. 답에 필요한 실제 문맥 |
| `benchmark_query` | 필수. 개인정보가 없는 공개용 검색 키워드. 개인 자산·대출·거래·가족상황 등 비공개 정보를 포함하지 않음 |
| `sources` | 공식 출처 1~3개. 각 항목의 `url`, `published_date`, `excerpt`, `date_excerpt` 필수 |
| `sources[].url` | 아래 허용 호스트의 특정 HTTPS HTML 문서. 기관 홈페이지 주소만으로 대신하지 않음 |
| `sources[].published_date` | 원문의 실제 발간일 `YYYY-MM-DD`. 미래 날짜나 수집일로 대체하지 않음 |
| `sources[].excerpt` / `date_excerpt` | 핵심 근거 인용 / 발간일을 확인할 원문 문장. 실제 본문과 일치해야 함 |
| `data_date` | 현재 환율·금리·시세 수치를 인용할 때 필수인 자료 기준일 `YYYY-MM-DD`, KST D-1/D0. 현재 수치를 쓰지 않으면 생략 가능 |

허용 호스트는 `*.go.kr`, `bok.or.kr`·`www.bok.or.kr`, `fss.or.kr`·`www.fss.or.kr`, `boj.or.jp`·`www.boj.or.jp`, `mof.go.jp`·`www.mof.go.jp`입니다. 금요일 정책용 허용 목록을 넓히는 변경은 아닙니다.

- 공식 HTML 원문을 직접 읽고 `excerpt`·`date_excerpt`의 실제 본문 일치와 날짜를 검증합니다. 출처 목록이나 입력 JSON만으로 원문 검증이 완료됐다고 보지 않습니다.
- `data_date`를 넣으면 `sources[].excerpt` 중 적어도 하나에 해당 관측일이 직접 포함되고 실제 공식 원문에서도 일치해야 합니다. 메타데이터의 날짜만 바꿔 오래된 수치를 현재로 만들지 않습니다. 관측일·조건·단위·통화를 대조하며 과거 기간 통계는 해당 기간을 명확히 한 비교·배경에만 씁니다.
- 공개 검색에는 검증한 `benchmark_query`만 사용합니다. 비공개 질문·문맥의 개인 금융수치나 자산·대출·거래·가족상황을 검색어로 보내거나 필수 키워드가 없을 때 자동 추출하지 않습니다.
- 과거 큐는 구조만 읽어 보존하고 최신성은 당일 계획에 맞는 적격 입력에 한해 검증합니다. 과거 생활경제 입력의 날짜가 지났다는 이유로 다른 요일의 정상 준비를 오류 처리하지 않습니다.
- 유료 준비 전에 검증하고 재시도·미디어 재개·`ready` 인계 때 원본 큐와 공식 원문을 다시 대조합니다. 저장 전에도 당일 계획·근거 유효성을 확인하며 기존 sourcechecks와 검수 기준을 유지합니다.
- 공식 PDF·차단 URL 등 현재 읽을 수 없는 자료, 리디렉션, 원문 변경, 인용·날짜 불일치, 미확인 현재 수치는 보류합니다. 다른 주제나 임의의 출처·수치·날짜로 대신하지 않습니다.
- 원본·원고·이미지·검증 기록은 기존 비공개 암호화 인계 경로로 보존합니다. 새 Secret·지속 접근 권한·유료 서비스·실행 예약을 만들지 않습니다.

## 글과 저장 기준

실제 질문의 답을 먼저 쓰고 적용 조건·수수료/비용·자료 기준일·독자가 확인할 절차를 설명합니다. 사용자의 자산·소비·매매·수익 경험을 창작하지 않고 특정 종목·상품을 억지로 연결하지 않습니다. 검증한 비교·체크리스트와 공식 직접 링크를 사용하며 근거가 부족하면 분량을 채우지 않습니다.

유래 전용 짧은 글 예외는 생활경제에 적용하지 않습니다. 기존 투자 이미지 예산(기본 3장, 본문 2,500자 이상 4장), 심화 실제 증거, 24/30·정확성/안전성 각 4/5, 기존 재작성·복구 한도를 유지합니다. 유료 호출이나 이미지 수를 늘려 부족한 실제 자료를 대신하지 않습니다.

수동·준비·저장·복구는 **KST 당일 합산 1편**입니다. 기존 요청 ID·원래 작업일·유료 이력·실제 저장일 영수증을 보존하며 과거 유료 원고를 자동 이월·재저장하지 않습니다. 최종 발행은 사용자가 직접 합니다.
