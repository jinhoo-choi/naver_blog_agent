# Naver Blog Agent

육아·투자·요리의 글감을 조사하고 초안을 작성·심사해 **네이버 블로그 임시저장까지만** 처리합니다. 최종 발행/예약발행은 사용자가 직접 합니다.

버전 0.2.0 · 요구사항 기준 2026-09-26 KST

## 흐름

n8n 스케줄 → GitHub Actions → Windows 실행기 → 웹 조사·작성 → 독립 웹 검수 → 중복/품질 게이트 → 원고 보관 → 네이버 임시저장 → 사용자 직접 발행

| 항목 | 구현 |
|---|---|
| 카테고리 | 육아·투자·요리, 하위 9개 분류 |
| 작성량 | KST 하루 후보 1~5건, 기본 3건. 탈락 시 저장 건수 감소 |
| 품질 | 6항목 30점 중 24점, 정확성·안전성 각각 4점 이상 |
| 출처 | 실제 검색 응답에 존재하는 URL만 허용, 검수도 웹 검색 |
| 재작성 | 보완 대상은 최대 1회 수정 후 재심사 |
| 상태 | checkout 밖 SQLite·원고 보관, 중복 실행 일일 한도 유지 |
| 저장 | 임시저장 버튼과 신규 완료 메시지가 확인돼야 성공 |
| 장애 | 미확인 저장은 자동 재전송 금지, 직접 확인 후 상태 확정 |
| 알림 | Telegram 선택 기능, 기본 비활성 |
| 이미지·게시판 | 이미지 자동생성·삽입 미포함, 게시판/발행 태그는 직접 확인 |

**실제 운영은 로컬 PC 등록, Secrets 입력, 최초 네이버 로그인 후 가능합니다.** 네이버 편집기 셀렉터는 실계정 확인 전입니다.

## 시작

1. [운영 가이드](docs/OPERATIONS.md)에 따라 Secrets와 PC 실행기를 설정합니다.
2. PC에서 `blogbot login`으로 네이버 최초 로그인을 완료합니다.
3. Actions → Naver Blog Draft → Run workflow에서 `count=1`, `mode=save`를 선택합니다.
4. 네이버 임시저장 목록과 내용을 직접 확인합니다.
5. n8n 파일을 가져와 스케줄을 활성화합니다.
