- 이미지 생성·삽입과 게시판 UI 자동설정은 현재 버전에 미포함.

## 운영 보완

- checkout 외부 상태 보관, KST 일일 예산을 API 호출 전 원자적으로 예약.
- 실제 검색 URL 대조, 독립 웹 검수, 점수 합계 재계산, 정확성·안전성 별도 문턱.
- 재작성 후 날짜·하위 분류·중복 재확인.
- 원고·심사 결과 로컬 보관, API 재호출 없는 승인 원고 저장 재시도.
- 임시저장 버튼만 조작, 신규 완료 메시지가 있어야 성공.
- 실패/중단 후 미확인 저장은 직접 목록 확인 후 재시도.
- 로컬 workflow는 owner의 main 수동/dispatch 및 활성화된 스케줄만 실행.
- 공개 PR CI는 GitHub-hosted 실행기에 한정.
- 설치·Secrets·로그인·복구 스크립트와 n8n 가져오기 파일 제공.

## 필요한 외부 연결

| 항목 | 상태 |
|---|---|
| Windows 실행기 | 사용자의 PC에 설치 필요 |
| API키·블로그 ID | GitHub Secrets 설정 필요. 현재 도구에는 Secrets 관리 기능 없음 |
| 네이버 최초 로그인 | 해당 PC에서 직접 로그인 필요 |
| 편집기·임시저장 실계정 확인 | 최초 실행 후 저장 목록 확인 필요 |
| n8n 인스턴스 | 연결 미제공, 가져오기 JSON 준비 |
| 자동 스케줄 | 초기 비활성, 연결 후 n8n 또는 GitHub 스케줄 중 하나 활성화 |

실계정 글 생성·임시저장 성공이나 운영 개시는 아직 주장하지 않습니다.
CI는 외부 계정 없이 코드의 게이트·상태 처리를 확인합니다.

## GitHub 반영 상태

- GitHub 앱의 쓰기 제한을 확인한 뒤 사용자 보안 로그인으로 브라우저에서 직접 커밋.
- 구현 소스·n8n 설정·설치 스크립트·운영 문서·Actions workflow를 main에 반영.
- GitHub PAT는 사용하거나 저장하지 않음.
- CI 상태는 저장소 Actions에서 확인. 실계정/유료 API 호출은 수행하지 않음.
