5. 제목은 매 글 실제 제목으로 바꾸며 날짜·수치·사진·영상·캡션·출처·링크는 `[교체: …]` 자리다. 실제 미디어·카드가 없는 원본의 자리표시자는 첨부 성공 증거가 아니다.

## 매 글 적용 순서

문체는 [VOICE](VOICE.md)의 `seonoo-voice-v1`을 적용한다. 템플릿의 글꼴·크기·색·구분선은 유지하고 실제 내용을 채울 때 도치·강조·유머를 선택한다. 장식을 위한 자리표시자나 모든 글에 복사하는 고정 농담은 만들지 않는다.

검증된 승인 템플릿 불러오기 → 내용·미디어 교체 → 관련 글 연결 → 태그5개 선정 → 실물 검수 → 기존 승인 범위의 저장. 실제 저장 확인 직후 [저장본 품질평가](CONTENT_QUALITY.md#임시저장-후-품질평가보완재평가--post-save-review-v1) → 별도 보완 → 수정 저장 확인 → 재평가 → 보고를 진행한다. 저장 직후 증거를 우선하며 재열기 금지·동시 편집 제한을 유지한다. 네이버 템플릿을 사용할 수 없으면 동일 서식 원본을 쓰고 미등록/미검증을 보고한다. 양식 때문에 새 글·유료 호출·발행 권한을 추가하지 않는다.

- 참고자료는 마무리 앞에 정리하고, 하단은 **마무리 → 함께 읽으면 좋은 글 → 해시태그** 순서로 둔다. 짧은 유래의 마무리는 한 문장으로 가능하며 반복 결론을 늘리지 않는다.
- 본문에 직접 맞는 대표 주제·구체적 대상·검색 의도·세부 내용의 서로 다른 태그를 **정확히5개** 고른다. 고정 목록 복사, 본문에 없는 인기어, 의미 없는 동의어/어순 반복은 제외한다. 5개는 편집 기준이며 네이버 공식 검색 최적값·조회수/상위노출 보장이 아니다.
- tags는 기존 JSON 배열을 사용한다. 모델 body에는 태그를 중복 쓰지 않는다. Work가 최종 본문 하단 태그 문단을 한 번만 확인하고 네이티브 태그도 같은5개와 대조한다. 후기 인계는 include_tags=false이므로 마지막에 한 번 추가한다. 부족하면 승인 본문 안에서 최소 보완하고 근거 있는5개 선정이 불가능하면 저장 전 사유를 보고한다. 태그만을 위한 추가 유료 호출은 없다.
- 직접 관련 있는 실제 공개 내 글1~2개만 선정한다. 정확한 개별 URL·소유자·공개 상태·본문을 확인하고 이어 읽을 이유를 짧게 쓴 뒤 네이버 링크 추가(URL 삽입) 카드로 넣는다. AI 영상→관련 제작법, 음식 유래→관련 음식/단어 유래, 운동→관련 부위/동작의 실제 접점을 확인한다. 임시저장·예약·삭제·미확인·무관한 글은 제외하며 적격 글이 없으면 구역을 생략한다.
- 카드 제목·대표 이미지·모바일 잘림·연결 대상을 검수한다. 일반 하이퍼링크를 네이버 카드 삽입 완료로 기록하지 않는다. 카드 생성 실패는 중복 삽입하지 말고 해당 단계의 미완료로 보고한다.
- 본문·소제목·캡션·실제 구분선·여백과 오래된 날짜/수치/URL, `[교체: …]` 등 자리표시자 잔존을 확인한다. 이미지/영상은 승인 원본과 대조하며 제공되지 않은 경험·반응·효과·실패·설정은 창작하지 않는다.
- 대표 이미지, 기존 AI 표시 기준, 카테고리, 공개 범위, 검색 허용, 예약 시각은 템플릿과 별개로 대조한다. 이번 요청은 이를 변경하는 권한이 아니다. 저장·발행은 AUTOMATION의 기존 범위·영수증·한도·중복방지를 따른다.
- 권한 거절·인증·CAPTCHA·플랫폼 제한은 우회하지 않는다. 시험 템플릿을 실제 원고로 저장/발행하지 않으며 실물 검수 통과 전 완료로 표시하지 않는다.

수동 작성과 기존 임시저장 수정은 AUTOMATION의 수동 콘텐츠 작성 예외를 따른다. 기존 원고에 시험 양식을 덮어쓰지 않고 필요한 구역만 편집한다.

## 소유자 최신 편집 보완 — concise-owner-v2

2026-10-14 08:40 KST의 7개 요청을 앞의 일반 편집 선택 기준보다 우선 적용한다. [VOICE](VOICE.md)의 concise-owner-v2 전개를 사용한다. **썸네일과 별개로 본문 설명용 삽화를 최소2장** 배치하고 서로 다른 설명 역할을 부여한다. 기존 실제 후기 사진·실행 캡처의 증거 요건, 재사용 우선·생성 상한·예산은 유지한다. 장수 충족을 확인하지 못하면 미완료로 보고하며 새 유료 자동 호출 권한을 추정하지 않는다.

썸네일·본문·표·캡션의 종목명은 정식 종목명을 쓴다. ‘한미’ 대신 **한미약품**, ‘알테’ 대신 **알테오젠**이다. 작은 화면에서도 전체 이름이 판독되게 줄을 나눈다. 투자 유의사항은 종목 글의 마지막에만 두고, 다른 글에는 넣지 않는다. 원본 출처 링크와 내부 사실 검증은 유지하되 산출근거/시장별 계산 방법 해설을 공개 본문에 늘어놓지 않는다.

종가와 과거 가격은 **네이버페이 일별 종가(NXT 반영)**로 통일한다. 현재가·프리마켓·KRX 기준가를 전날 종가 대신 쓰지 않는다. 날짜별 종가를 실제 표에서 확인하고 같은 시계열로 비교한다. 가격과 별개인 투자자 수급의 시장·기간·단위는 내부 검수 기록에 보존한다. 실제 데이터 미확보 시 임의 대체하거나 기존 차트의 값을 혼합하지 않는다.
