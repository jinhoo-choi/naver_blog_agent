# 프로젝트 상태

대화 맥락 기준: 2026-09-27 KST · 구현 버전 0.4.0

## 사용자 확정 사항

- 블로그명·프로필명 `써누애비`, 소개글·프로필 이미지·상단 스킨 적용 완료.
- 네이버 카테고리: 육아 1, 요리 6, 투자 7. 최종 발행은 사용자 직접 처리.
- 요리는 제공한 레시피와 실제 사진이 모두 있을 때만 작성.
- 육아는 선우 관련 실제 질문을 입력으로 작성. 월령·증상·경험을 추정하지 않음.
- 투자는 `jinhoo-choi/kis-community-bot`의 기준 통과 자료만 읽기 전용으로 사용.
- 작성 전 네이버 검색 상단 5~10개 글의 구조를 비교하되 조회수 순위라고 표현하지 않음.
- 육아·투자 이미지는 밝은 생성 이미지 사용. 요리는 사용자 원본 사진만 사용.

## 현재 구현

- 대제목 4개 이상·소제목·짧은 문단, 육아 1,800자 최소 기준.
- 검색 노출 글의 글자·이미지·소제목·표·FAQ·체크리스트 메타데이터만 보관.
- 1차 자료 기반 사실 검수와 네이버 구조 비교를 분리.
- 육아 2장·투자 1장 생성 후 대제목 사이에 첨부. 실패 시 저장 중지.
- 네이버 카테고리 번호로 편집기 진입, SmartEditor HTML 서식·사진 업로드, 저장 목록 제목 확인.
- 요리 입력의 레시피·사진·해시 검증, 투자 원본 커밋·기준일 보존.
- 발행 자동화 없음. 저장 불확실 시 자동 재시도 중지.

## 실계정 반영

- 목튜브 글: 검색 상단 7개 구조 비교, 약 3천 자, 대제목 5개, 사진 2장으로 임시저장.
- 호명반응 글: 검색 상단 5개 구조 비교, 약 3천 자, 대제목 5개, 밝은 AI 일러스트 2장으로 교체 후 임시저장.
- 손상·중복 호명반응 초안 3건 삭제. 현재 임시저장 목록은 위 육아 글 2건.
- 게시글은 발행하지 않음.

## 현재 운영: 출근 전 임시저장

2026-09-27 요청을 반영해 ChatGPT Work 예약 작업을 활성화했습니다.

| 항목 | 설정 |
|---|---|
| 실행일 | 월~금, 한국 법정·대체·임시공휴일 및 근로자의 날 제외 |
| 시작 | Asia/Seoul 오전 5시 전후의 유연한 예약 |
| 첫 예정일 | 2026-09-28 월요일 |
| 목표 | 해당 영업일 신규 임시저장 3건. 같은 날짜 재실행 시 누적 3건 |
| 배분 | 기본 육아 2건 + 투자 1건. 실제 요리 자료가 있으면 육아 1건 대체 |
| 실행 경로 | 현재 연결된 Cloud Browser의 네이버 세션 |
| 최종 발행 | 사용자 직접 검토·발행 |
| 예외 | 적격 자료 부족·인증 만료·저장 실패 시 완료 건수와 부족 사유 보고 |

예약 지침에는 최신 프로젝트 문서 읽기, 실제 육아 질문 조회, 투자 원본 심사,
네이버 상단 노출 5~10건 구조 비교, 밝은 이미지, 저장 확인, 주제·당일 중복 방지가 포함됩니다.
가용한 다른 입력을 검토해 3건 완성을 시도하며, 자료·품질 기준을 낮추거나 경험을 창작하지 않습니다.
기존 목튜브·호명반응 2건은 첫 실행의 신규 3건에 포함하지 않습니다.
예약 등록·네이버 편집기와 임시저장 접근·투자 원본 읽기를 확인했습니다.
무인 예약의 첫 실제 실행·3건 저장 완료는 아직 미래의 확인 항목입니다.

현재 예약은 사용자 PC의 Windows runner를 호출하지 않습니다.
GitHub Actions와 n8n은 별도 대안이며, 중복 실행 방지를 위해 함께 활성화하지 않습니다.
네이버 세션 만료나 CAPTCHA는 사용자 인증이 필요할 수 있으며 우회하지 않습니다.

## PC 실행기 대안의 연결 상태

| 항목 | 상태 |
|---|---|
| OPENAI_API_KEY | GitHub Secret 등록 확인. 값은 조회하지 않음 |
| NAVER_BLOG_ID | GitHub Secret에 `choijku` 등록 |
| GitHub Variables | 경로·모델·후보 수·스케줄/알림 플래그 등록 |
| Windows self-hosted runner | 사용자 PC에서 1회 등록 필요 |
| 네이버 최초 로그인 | 실행기 PC에서 1회 필요 |
| GitHub 자동 스케줄 | BLOG_SCHEDULE_ENABLED=false를 2026-09-27 화면에서 확인. ChatGPT 예약과 동시 활성화 금지 |
| n8n | 선택 연결. 가져오기 JSON 준비 |

PAT는 사용하거나 저장하지 않았습니다. PC 실행기는 ChatGPT 대화를 상시 수집하지 않으며 실제 질문을 개인 입력 큐에 등록합니다. 현재 ChatGPT 예약은 실행 시 프로젝트 대화·개인 맥락에서 확인한 실제 질문을 사용합니다.
