### 사용자 편집에서 가져온 문체·구성 예시

아래는 ESL 글에서 확인한 편집 방향입니다. 다른 글에 경험·의학 사실을 복사하지 않고 문장 호흡과 배치만 참고합니다.

- 도입: 확인된 개인 경험을 짧게 소개하고 바로 본론으로 넘어갑니다. 경험 뒤의 “다만 이 경험을 모든 아기의…” 같은 중복 면책은 복원하지 않습니다. 결과 해석에 필요한 대상·조건은 관련 사실 문장에 유지합니다.
- 소제목: “그림으로 확인하는 자세와 순서”, “1. 준비 · 발 받침과 쿠션”, “2. 자세 · 옆으로 충분히 지지”처럼 실제 내용을 드러냅니다. 준비 → 자세 → 수유 → 멈춤의 순서를 유지하고 각 단계의 문단을 나눕니다.
- 근거 구역: 관찰 결과를 먼저 쓰고 연구 대상·비교 조건·필요한 적용 범위를 같은 사실 문장이나 짧은 문단에 자연스럽게 연결합니다. 매번 별도 경고를 덧붙이지 않습니다.
- 배치: 도입 문단 → 실제 구분선 → 적용 대상 구역 → 실제 구분선 → 자세와 순서 구역 → 실제 구분선 → 연구 구역 → 실제 구분선 → 안전 안내 구역 → 실제 구분선 → 참고자료. 세부 단계는 같은 구역 안의 소제목으로 나눕니다. 이 배열은 ESL 예시이며 모든 글의 고정 목차가 아닙니다.
- 실제 삽화 설명 예시: “병원 안내를 바탕으로 제작한 설명용 삽화입니다.” 다음 줄에 “실제 수유 자세는 아래 링크의 병원 원문 사진과 함께 확인하세요.”를 둡니다. 짧은 두 줄의 호흡을 참고하되 필요한 안전 조건을 일괄 삭제하는 규칙으로 확대하지 않습니다.
- 삽화 바로 아래의 원문 안내는 자세 사진이 있는 병원 자료로, 안전수면 카드는 안전수면 문단으로 연결합니다. 서로 다른 주제의 카드를 가까이 있다는 이유로 바꾸어 쓰지 않습니다. 이미지 스타일·장수·원본 자료 요건은 기존 별도 규칙을 유지합니다.

## 요리

레시피 또는 사진 한쪽만 있으면 생성하지 않습니다. 외부 레시피, 스톡 이미지, AI 대체 이미지를 넣지 않습니다.
재료·계량·시간·온도·순서는 원본 값을 유지합니다. 미제공 항목을 모델이 채우지 않습니다.
가족 반응, 맛 평가, 직접 해본 실패담도 사용자가 제공한 내용만 반영합니다.
사진은 원본 파일을 로컬 큐로 복사해 보관하고 변경 여부를 해시로 확인합니다.
현재 작성 모델에는 사진 캡션만 전달하며 사진 내용을 분석했다고 주장하지 않습니다. 원본 사진은 입력 순서대로 첨부합니다.
사진의 정확한 위치·캡션·대표 이미지는 최종 발행 전에 직접 확인합니다.
요리는 정기 주간 배분에 포함하지 않습니다.

## 육아

월령별 발달, 지루성 두피염, 목튜브 사용 여부는 사용자가 제시한 질문 유형의 예입니다.

정확한 월령을 제공하면 반영하고, 모르면 아이 나이를 추정하지 않고 월령별 적용 조건을 구분합니다.

질문을 특정 진단으로 바꾸거나 진료받은 경험·치료 효과를 창작하지 않습니다.
공개 원고에서는 아이 실명·생년월일·사적 병력을 생략합니다.

가족-AI 튜토리얼도 네이버 육아 카테고리 1에 저장합니다. 특정 요일의 의무 편성은 없으며
새 영상·실제 제작 자료가 있을 때만 선택합니다. 하위유형을 입력에서 명시해야 하며
일반 질문의 제목에 AI 단어가 있다는 이유로 자동 전환하거나 과거 영상을 재활용해 수를 채우지 않습니다.
실제 제작 환경·입력·결과·공식 기능을 확인하고 미제공 프롬프트·실패·효과를 만들지 않습니다.
사용자가 기존 수동 초안을 특정 편집일에 배정한 경우 DAILY_PLAN의 날짜별 예약을 따릅니다.
