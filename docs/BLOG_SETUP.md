## 공통 문체·근거 편집 — 2026-10-03

- 육아·운동·투자·요리 모두 자연스러운 습니다체, 대체로 1~2문장인 모바일 문단을 사용합니다. 원문 인용·사용자가 제공한 실제 발언의 말투는 보존합니다. 벤치마크 말투가 이 기준을 덮어쓰지 않습니다.
- 반복되는 정의형 어미와 방어적 메타 설명을 줄입니다. '방법이에요/뜻해요'를 '방법입니다/뜻합니다'로만 바꾸는 대신 핵심 사실과 독자가 할 행동을 바로 설명합니다. '이 글에서는 … 설명하지 않습니다/구분해 읽어 주세요' 같은 안내를 반복하지 않습니다.
- 제목·소제목은 구체적인 명사구나 분명한 질문으로 씁니다. 상투적 대비 제목보다 'ESL 수유 자세와 순서'처럼 실제 내용을 드러냅니다.
- 연구의 관찰 결과·비교 대상을 먼저 설명하고 대상·조건·범위의 한계를 같은 구역에서 한 번 덧붙입니다. 한계만으로 연구 설명을 대신하거나 미확인 결과·치료 효과를 추가하지 않습니다.
- 반복 면책은 정리하되 수유 중단·응급 대응·안전수면 등 필수 행동과 각 단계에 필요한 안전 조건은 보존합니다. 사용자 확인 경험은 짧고 익명으로, 임상 근거와 분리하며 미제공 증상·기간·효과 크기를 만들지 않습니다.
- 2026-10-03 사용자 직접 편집 반영: 도입의 경험은 짧게 쓰고 같은 주어·방어적인 일반화 면책을 반복하지 않습니다. 연구 대상과 효과 범위의 한계는 해당 근거 구역에 남깁니다. 자신 있는 습니다체는 치료 효과를 단정하라는 뜻이 아닙니다. 삽화 설명은 무엇을 확인할지와 관련 원문 안내 위주로 간결하게 씁니다.
- **구분선·줄바꿈은 필수입니다.** 도입 뒤 각 대제목 구역과 참고자료 앞에 실제 기본 실선 구분선을 둡니다. 문단 사이에는 의미별 빈 줄을 넣고, 대체로 1~2문장씩 끊어 모바일에서 읽기 쉽게 만듭니다. 원고의 `##` 구조와 빈 줄을 렌더러에 전달하며 `---` 문자를 본문에 노출하지 않습니다. 일반 문단마다 구분선을 넣거나 문장 중간을 글자 수로 자르지 않습니다. 편집기에 붙인 뒤에도 실제 구분선과 문단 나눔이 유지되는지 확인합니다.

### 사용자 편집에서 가져온 문체·구성 예시

아래는 ESL 글에서 확인한 편집 방향입니다. 다른 글에 경험·의학 사실을 복사하지 않고 문장 호흡과 배치만 참고합니다.

- 도입: 확인된 개인 경험을 짧게 소개하고 바로 본론으로 넘어갑니다. 경험 뒤의 “다만 이 경험을 모든 아기의…” 같은 중복 면책은 복원하지 않습니다. 연구 구역의 한계는 유지합니다.
- 소제목: “그림으로 확인하는 자세와 순서”, “1. 준비 · 발 받침과 쿠션”, “2. 자세 · 옆으로 충분히 지지”처럼 실제 내용을 드러냅니다. 준비 → 자세 → 수유 → 멈춤의 순서를 유지하고 각 단계의 문단을 나눕니다.
- 근거 구역: 관찰 결과 → 연구 대상·비교 조건 → 적용 범위의 한계를 각각 짧은 문단으로 배치합니다.
- 배치: 도입 문단 → 실제 구분선 → 적용 대상 구역 → 실제 구분선 → 자세와 순서 구역 → 실제 구분선 → 연구 구역 → 실제 구분선 → 안전 안내 구역 → 실제 구분선 → 참고자료. 세부 단계는 같은 구역 안의 소제목으로 나눕니다. 이 배열은 ESL 예시이며 모든 글의 고정 목차가 아닙니다.
- 실제 삽화 설명 예시: “병원 안내를 바탕으로 제작한 설명용 삽화입니다.” 다음 줄에 “실제 수유 자세는 아래 링크의 병원 원문 사진과 함께 확인하세요.”를 둡니다. 짧은 두 줄의 호흡을 참고하되 필요한 안전 조건을 일괄 삭제하는 규칙으로 확대하지 않습니다.
- 삽화 바로 아래의 원문 안내는 자세 사진이 있는 병원 자료로, 안전수면 카드는 안전수면 문단으로 연결합니다. 서로 다른 주제의 카드를 가까이 있다는 이유로 바꾸어 쓰지 않습니다. 이미지 스타일·장수·원본 자료 요건은 기존 별도 규칙을 유지합니다.

## 요리

레시피 또는 사진 한쪽만 있으면 생성하지 않습니다. 외부 레시피, 스톡 이미지, AI 대체 이미지를 넣지 않습니다.
재료·계량·시간·온도·순서는 원본 값을 유지합니다. 미제공 항목을 모델이 채우지 않습니다.
가족 반응, 맛 평가, 직접 해본 실패담도 사용자가 제공한 내용만 반영합니다.
사진은 원본 파일을 로컬 큐로 복사해 보관하고 변경 여부를 해시로 확인합니다.
현재 작성 모델에는 사진 캡션만 전달하며 사진 내용을 분석했다고 주장하지 않습니다. 원본 사진은 입력 순서대로 첨부합니다.
사진의 정확한 위치·캡션·대표 이미지는 최종 발행 전에 직접 확인합니다.

## 육아

월령별 발달, 지루성 두피염, 목튜브 사용 여부는 사용자가 제시한 질문 유형의 예입니다.
예시를 자동 예약하지 않으며 실제 질문을 입력 큐에 등록하면 처리합니다.
정확한 월령을 제공하면 반영하고, 모르면 아이 나이를 추정하지 않고 월령별 적용 조건을 구분합니다.
의료·발달·제품 안전 주장은 공공기관·학회·병원 등 1차 근거를 확인합니다.
질문을 특정 진단으로 바꾸거나 진료받은 경험·치료 효과를 창작하지 않습니다.
공개 원고에서는 아이 실명·생년월일·사적 병력을 생략합니다.

## 검색 구조 비교와 이미지

작성 API는 본문·비교표·출처를 준비하고 캡처할 실제 원문/화면의 필요성을 확인합니다. 캡처 파일이 아직 없는 텍스트 심사에서 미생성 이미지를 이유로 반복 재작성하지 않습니다.
Work 저장 단계에서 원문/실제 UI의 필요한 부분을 캡처하거나 제공 원본을 사용하며, 파일·출처URL·확인시각·삽입 위치를 비공개 작업 기록에 남깁니다. 계정 정보가 드러난 캡처는 그대로 넣지 않습니다. 캡처·사진의 재사용 권한과 허용 범위를 확인하고 필요한 부분만 사용합니다. 출처 표기만으로 재사용 권한이 생긴다고 보지 않습니다. 권한이 확인되지 않으면 허용된 다른 실제 자료를 찾고 필수 자료를 확보하지 못하면 보류합니다. 외부 페이지 전체 복제나 다른 블로거의 사진 재사용은 하지 않습니다.
