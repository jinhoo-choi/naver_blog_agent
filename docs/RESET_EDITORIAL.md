# 써누애비 작성·검증 — strategy-reset-v1

2026-10-15 소유자 승인. 실행·범위는 RESET_OPERATIONS, 서식·미디어는 RESET_DESIGN을 따른다.
기존 장문 규칙과 점수표는 새 글에 겹쳐 붙이지 않는다. 기존 필수 사실성·안전성·광고 고지·권한은 유지한다.

## 작성 전 네 질문
1. 누구의 어떤 질문에 답하는가? 실제 검색어·실제 유입어·공개 자료의 질문으로 표현한다.
2. 가장 가까운 내 글과 무엇이 다른가? 기존 URL·본문·기존 답·새 질문/조건/근거·독자가 얻는 차이를 대조한다.
3. 어떤 원문/실제 자료가 뒷받침하는가? 사실·경험·저자 분석을 나누고 핵심 주장별 근거를 연결한다.
4. 읽은 뒤 어떤 판단이나 행동이 쉬워지는가? 반복 요약이나 출처 소개만으로 끝내지 않는다.

하나라도 핵심 근거가 없으면 새 공개 후보에서 보류한다. 경험이 없다는 이유로 경험을 요구하거나 만들지 않는다. 비교·조건 차이·직접 계산·재현 자료도 고유 가치가 될 수 있다.

## 원고 세 유형
- 후기: 실제 결과/선택 → 제공된 과정·사진 → 장단점·조건 → 비슷한 상황의 선택 기준. 소유자 실사진/사용 기록 없이 후기·내돈내산을 쓰지 않는다.
- 정보·비교: 질문의 답 → 필요한 개요 → 조건별 차이/근거/계산 → 판단에 필요한 기준. 가정 사례는 가정이라고 표시한다.
- 재현 튜토리얼: 실제 결과 → 실제 설정·재료 → 재현 순서 → 사용한 입력/프롬프트·필요한 조건. 가짜 UI·미사용 설정·실패 경험을 만들지 않는다.

템플릿의 목차는 선택지다. 모든 글에 FAQ·연구설계·마무리·동일 농담을 붙이지 않는다. 글자수·이미지 개수로 내용을 채우지 않는다.

## 제목과 문체
- 제목은 핵심 질문 하나와 실제 답의 범위. 동의어·인기어·세팅/수행/순서/교정의 연속 나열을 줄인다. 길이·앞배치·반복 횟수를 공식 랭킹 규칙으로 만들지 않는다.
- 첫1~2문장에 답과 적용 대상을 준다. 개요·조건·의미를 지워 짧게 만들지 않는다.
- 쉬운 습니다체, 한 문장 한 생각, 문단1~3문장. 도치·강조·익살은 자연스러울 때만 선택하며 횟수 검사·고정 문구를 없앤다. 의료·동작·안전·금융 조건은 평이하고 정확하게 쓴다.
- 경험·아기 반응·효과·사용기간·투자수익을 창작하지 않는다. 전문 주장은 공공기관·학회·공식 원문으로 확인한다. 필요한 불확실성과 광고/제휴 고지는 보존한다.
- ‘오늘은 알아보겠습니다’·‘도움이 되셨길’ 등 상투 문구, 내부 검수 메모·반복 경고·동일 결론을 공개 본문에서 뺀다.

## 검증과 기록
- 핵심 주장별 실제 원문·날짜·대상·단위·조건을 대조한다. 최신 금융/제도는 실행 시 재조회한다.
- 내용은 네 질문의 실제 문장 위치로 평가한다. 코어 호환 검수 점수와 원문별 source_checks는 한 번만 기록하며 자체35점을 검색 점수로 부르지 않는다.
- 허위 경험·핵심 오류·중대한 안전/금융 오도·무단 복제·민감정보 노출은 총점과 무관하게 보류한다.
- 검색 미발견과 편집 품질을 분리한다. 개선 후 검색 결과가 바뀌기 전 원인을 확정하지 않는다.
- 구·신 글이 같은 질문이면 대표 URL 수정부터 검토한다. 검색 유입·기존 인용·정확성을 보고 대표를 고르며 최신 날짜만으로 선택하지 않는다.
