# 프로젝트 상태

대화 맥락 기준: 2026-09-26 KST · 구현 버전 0.3.0

## 사용자 확정 사항

- GitHub `jinhoo-choi/naver_blog_agent`에 구축. 필요하면 PAT 사용 가능.
- n8n·GitHub로 작성부터 네이버 임시저장까지 자동화. 최종 발행·예약발행은 사용자 직접 클릭.
- 하루 후보 1~5건. 글감이 없으면 건수를 맞추지 않음.
- **요리: 사용자가 올린 레시피와 사진이 모두 있을 때만 작성.**
- **육아: 선우와 관련해 실제로 물어본 질문을 글로 작성.**
  월령별 발달, 지루성 두피염, 목튜브 사용 여부는 질문 유형 예시이며 자동 예약 목록이 아님.
- **투자: 기존 커뮤니티 게시글 생성봇 기반으로 작성.** 해당 저장소는 `jinhoo-choi/kis-community-bot`으로 확인.
- 키·계정 정보는 GitHub Secrets에 보관.

## 반영 내용

- 기존 자동 주제 선정은 제거하고 카테고리별 원본 입력을 필수로 변경.
- 요리 레시피·사진 검증, 원본 사진 사본·해시 보관, 입력 순서대로 네이버 첨부 처리.
- 실제 질문·선택적 월령·조건을 받는 육아 입력 큐. 미제공 증상·체험담·나이 창작 금지.
- 커뮤니티 봇 최종 결과를 읽는 전용 어댑터. 원본 봇을 실행·수정하거나 알림을 보내지 않음.
- 투자 원본 ID·커밋·자료 기준일 보존, 직원 배정·내부 진단 필드 제외, 별도 블로그 심사.
- 사용자 입력이 없거나 원본을 이미 처리했으면 유료 모델 호출 없이 종료.
- 각 카테고리의 게시글 구조를 설정·작성·검수 프롬프트에 반영.
- checkout 밖 SQLite·원고·사진 큐. KST 후보 한도와 원본 중복을 원자적으로 제한.
- 검수 6축, 24/30점, 정확성·안전성 각 4점. 재작성 최대 1회.
- 네이버 임시저장 신규 완료 메시지 확인. 미확인 저장은 직접 확인 후 복구.
- 공개 PR CI는 GitHub 제공 실행기. 로컬 작업은 owner/main 수동·dispatch·활성화된 스케줄만 실행.

## 구현 기본값

GPT-5, 후보 3건, Windows Chrome 실행기, n8n 07:00 KST는 변경 가능한 기본값입니다.
`생활연구소`는 미확정 제안명입니다. Telegram은 선택 기능이며 기본 비활성입니다.
투자는 최근 7일 자료, 사실성·준법성 각 4, fit 3, 환산 점수 14/20 이상을 후보로 받습니다.

## 남은 운영 연결

| 항목 | 상태 |
|---|---|
| Windows 실행기 | 사용자 PC 등록 필요 |
| GitHub Variables | 8개 등록 완료. 기본 3건·save, 스케줄·알림 false |
| OPENAI_API_KEY·NAVER_BLOG_ID | GitHub Secrets 미등록. 입력 필요 |
| 네이버 최초 로그인 | 실행기 PC에서 직접 로그인 필요 |
| 편집기·임시저장·사진 첨부 | 실계정 확인 필요. 사진 셀렉터는 확인 전 빈 값으로 둠 |
| 질문·요리 자료 | 개인 입력 큐에 등록 필요. ChatGPT 대화 상시 수집 연결은 없음 |
| n8n | 인스턴스 연결 미제공, 가져오기 JSON 준비 |
| 자동 스케줄 | 초기 비활성. 연결 후 n8n 또는 GitHub 중 하나 활성화 |

사진 첨부 설정 전 요리 원고는 로컬 APPROVED 상태로 남고 SETUP_REQUIRED를 표시합니다.
네이버 실계정 저장이나 실제 운영 개시를 완료했다고 주장하지 않습니다.

## GitHub 작업 이력

GitHub 앱의 쓰기 제한 때문에 사용자 보안 로그인 후 웹에서 직접 커밋했습니다.
PAT는 사용하거나 저장하지 않았습니다. 유료 모델·네이버 실계정 호출과 외부 알림 발송은 수행하지 않았습니다.
GitHub CI는 외부 계정 없이 입력 조건·원본 중복·일일 한도·미확인 저장 처리를 확인합니다.
2026-09-26 현재 저장소 Variables 8개를 등록했고, Repository Secrets와 self-hosted runner는 비어 있음을 확인했습니다.
