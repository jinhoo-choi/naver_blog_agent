# 써누애비 서식·미디어 — strategy-reset-v1

2026-10-15 소유자 승인. edit-mobile-blog를 적용한다. 새 외형을 만들지 않고 승인된 써누애비 서식을 재사용한다.
실행은 RESET_OPERATIONS, 내용은 RESET_EDITORIAL이 기준이다.

- 나눔고딕, 본문16px, 대제목24px, 필요한 소제목19px, 강조 #28564f, 행간1.9. 기본 실선·문단 여백. 캡션은 편집기 정규화11/12px 차이를 실제 화면에서 확인한다.
- 글자 수에 맞춘 강제 줄바꿈·전체 볼드·과한 빈 문단을 쓰지 않는다. 모바일 표는2~3열 우선, 머리행 음영·가운데 정렬. 넓은 비교가 꼭 필요하면 표를 나누거나 실제 모바일 가독성을 검증한다.
- 썸네일은 실제 질문과 얻을 답을 짧게 표시한다. 흰 바탕·굵은 검정 선·둥근 인물·세이지/노랑의 기존 이미지 계열을 유지한다.
- 이미지 수는 고유 설명 역할로 정한다. 본문 최소2장·태그 정확히5개를 새 필수 발행 조건으로 강제하지 않는다. 기존 생성 상한/복구 예산은 그대로며 장식 이미지를 추가하지 않는다.
- 사진은 실제 편집기 ‘사진 추가’로 등록한다. 이미지 복사·붙여넣기만으로 첨부 완료를 선언하지 않는다. 원본 해시·등록·로딩·대표 선택·순서를 확인한다.
- 생성 삽화는 경험·실제 화면·역사·제품 효과의 증거가 아니다. 필요한 AI 표시와 실제/설명용 구분을 유지한다. 인체·접점·관절·기구·동작이 부정확하면 교체 또는 보류한다.
- 출처·상품/서비스·직접 관련된 내 글은 ‘URL 삽입’으로 실제 카드 생성·제목·미리보기·연결을 확인한다. 주소 나열·일반 앵커만 넣고 카드 완료라고 기록하지 않는다. 적격 관련 글이 없으면 구역을 생략한다.
- 태그는 실제 주제·질문에 맞는 소수만 사용하고 같은 단어 변형이나 무관 인기어로 수를 채우지 않는다. 본문과 네이티브 태그를 중복 나열하지 않는다.
- 참고자료는 필요한 사실 가까이 또는 하단에, 마무리는 새 판단이 있을 때만. 관련 글은 다음 질문으로 자연스럽게 이어질 때1~2개 카드.
- 저장 후 PC·모바일360px 전체 제목/본문/그림/표/카드/하단을 읽는다. 실제 사진·카드·표·대표·공개/검색 설정·저장 증거를 확인한다. 목록의 제목만으로 실물 평가 완료라고 하지 않는다.
- 새3유형은 기존 templates/parenting.html(후기), investment.html(정보·비교), ai-video.html(재현)을 사용한다. 로컬 원본 변경과 네이버 ‘내 템플릿’ 등록/불러오기 검증은 별도다.
