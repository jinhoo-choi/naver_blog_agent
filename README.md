# Naver Blog Agent

**사용자 원본을 작성·검수한 뒤 Work에서 임시저장·공개 발행하고 교류 결과를 기록합니다.** 2026-10-10 자동 발행 승인 범위·단계별 검수·중복 방지는 [AUTOMATION](docs/AUTOMATION.md)을 따릅니다. API 준비 성공과 실제 네이버 발행 성공은 별개입니다.

운영 계획 기준 2026-10-10 KST · 새 주간 편성 적용 시작 2026-10-12 KST (`weekly-2221-v1`) · 수요일 `life-economics-v1` · 금요일 `weekly-policy-v1`

**매일 1편**: 10월 12일부터 월·토 육아, 화·일 이름의 유래, 수 생활경제(투자 7), 목 운동, 금 정책 투자입니다.
2026-10-05는 `daily-deep-511-v1`, 10월 6~11일은 `weekly-4111-v1`과 기존 수동 슬롯·입력 홀드를 그대로 보존합니다. 유래는 짧은 글이며 나머지 정기 글의 심화 기준을 그대로 적용하지 않습니다.
가족-AI 튜토리얼은 새 영상·실제 제작 자료가 있을 때만 육아(네이버 1)의 선택적 편집 하위유형으로 다룹니다. 화·토 AI 의무 편성은 없습니다.
새 편성의 첫 코호트는 10월 12~25일입니다. 글별 발행일 포함 7개 일자(D0~D6)와 유입 유형별 지표를 비교하고, 11월 1일 이후 집계 완료를 확인해 검토합니다. 자동 복귀·계획 만료는 없습니다.
전체 운영 기준과 전환 확인은 [DAILY_PLAN](docs/DAILY_PLAN.md)을 따릅니다.

| 카테고리 | 입력 | 게시글 구조 |
|---|---|---|
| 요리 | 사용자가 올린 레시피와 사진이 모두 있을 때만 | 소개·재료 → 조리 순서 → 제공된 팁·사진 설명 |
| 육아 | 선우 관련 실제 질문 | 질문·핵심 답변 → 월령별 조건·근거 → 실천 방법·주의사항 |
| 가족-AI | 새 영상·실제 소유자 제작 자료가 있을 때만, 육아 하위유형 | 실제 환경·결과 → 재현 단계·설정 → 체크리스트·공식 직접 링크 |
| 이름의 유래 | 사용자가 실제로 물어본 이름·단어의 유래 | 별도 연재 소개 → 첫 1~2문장 답 → 확인된 유래·출처 |
| 운동 | 실제 소유자 질문 | 준비·수행 → 올바른 자세·오류 → 안전장치·중단 신호 |
| 투자: 생활경제(수) | 소유자의 실제 질문과 직접 확인한 공식 자료 | 질문의 답 → 환율·금리·생활 금융의 조건·비용 → 실제 판단에 쓸 비교·체크리스트 → 출처 |
| 투자: 정책(금) | KIS 통과 원본 중 최근 5일 새 정책 1건과 검증된 비공개 근거 묶음 | 확인된 변화 → 기업에 갖는 의미·관계 수준 → 실제 다음 일정·조건 → 출처 |

실제 당일 입력이 없으면 보류합니다. 편성 승인만으로 새 후보를 등록하지 않으며 엔화·육아 관련 생활경제·K-GX 예시 주제는 미선정입니다. 14개 주제를 미리 채우거나 다른 카테고리로 대체하지 않습니다.
수요일 생활경제는 [LIFE_ECONOMICS](docs/LIFE_ECONOMICS.md)의 소유자 질문·공식 원문 검증을 사용합니다. 종목 연결이나 KIS 정책 통과를 필수 조건으로 강제하지 않습니다.
금요일 투자는 [WEEKLY_POLICY](docs/WEEKLY_POLICY.md)의 최근 **5 calendar days, D-4~D0** 안에 실제 발표·새 단계가 확인된 KIS `policy` 원본 1건만 사용합니다. 당일 07:00 KST 이후 최신 export 준비 확인은 별도이며 가격·수급 D-1/D0, 원본 점수(20점 환산 최소 14점)·fatal, 하루 1편 한도는 유지합니다. 근거가 없으면 보류하고 리포트·공시로 대체하지 않습니다. 요리는 정기 배분 밖의 별도 요청입니다.

## 자동화 흐름

실제 입력 큐 + 금요일 적격 커뮤니티 자료 → 기존 09:00 KST API 준비 → 암호화 인계 → 09:15/11:15 Work 검수·저장·발행. 교류는 12:05/16:05/20:05, 트렌드·실적은 20:05 교류 후 한 번 수행합니다.

- 큐: `blogbot enqueue --file <입력.json>`으로 로컬 PC에 등록합니다.
- 금요일 정책 투자: 원본 저장소의 당일 최신 export와 제한된 5일 커밋 이력을 고정해 읽으며 실행·수정·발송하지 않습니다. 적격 원본에만 별도 등록한 비공개 정책 근거를 연결합니다. `import-policy-evidence` 등록과 암호화 상태 운반을 마치기 전에는 기존 실행기가 새 근거를 소비하지 못합니다.
- 주제 선정 전: [Creator Advisor 절차](docs/CREATOR_TRENDS.md)에 따라 관찰된 검색어·게시물 유입순위 스냅샷을 비교합니다. 09:00 준비 전에 전달된 실제 근거만 사용하며 미확인·만료는 명시합니다. 저녁 Work가 실제 관찰한 공개 메타데이터를 config/creator-trends.json으로 전달하며 유효한 최신 입력만 사용합니다. 등록 성공과 다음 실행 소비는 따로 확인합니다.
- 품질: 6항목 30점 중 24점 이상, 정확성·안전성 각각 4점 이상. 재작성 최대 1회.
- 근거: 해당 주제의 1차 자료로 사실을 검수합니다. 네이버 검색 상단 5~10개 글은 구조·문체 특성만 비교하며 문장·주장·경험은 복제하지 않습니다.
- 구성: 육아·운동·투자는 기존 주제별 구조와 이미지 계획을 유지합니다. 유래는 본문 약 350~600자, 최소 소제목·실제 구분선·의미 있는 단어 강조와 제공·승인된 썸네일만 사용합니다. 정확한 분량을 채우기 위해 늘리거나 줄이지 않습니다.
- 중복: 원본 ID당 한 번만 생성하고 KST 일일 후보 한도를 API 호출 전에 예약합니다. 준비·저장·복구 합산 1편이며 당일 재시도는 같은 ID·기존 한도를 재사용합니다.
- 심화: 실제 근거와 공식 직접 링크를 확인하고, 글의 질문을 해결하는 실천 단계·비교·체크리스트를 필요한 경우에만 씁니다. 후기·AI 재현에 필요한 실제 사진·결과가 없으면 보류하며 일반 정보 글에 자료 수량을 일률 강제하지 않습니다.
- 비용: 기존 모델·이미지 생성 상한·재시도·심사 문턱을 유지합니다. 실제 이미지 수는 고유 설명 구역에 맞춥니다. 과거 날짜의 유료 원고는 보존·보류하며 자동 재과금·재저장하지 않습니다.
- 원고·사진·이력: 공개 저장소 밖의 로컬 PC에 보관합니다.
- 저장: 임시저장 완료 메시지가 있어야 성공 처리하며 미확인 저장은 자동 재시도하지 않습니다.

## 운영 연결

**구성 반영과 실제 준비·저장 결과는 별개입니다.** 과거 PR #21의 main 반영, 당시 외부 Work 지시문 동기화, 10월 5일 자연 준비의 예약 건너뜀을 확인했습니다. 현재 Work 지시문·예약 등록 결과는 [AUTOMATION](docs/AUTOMATION.md)과 [STATE](docs/STATE.md)에서 확인합니다. 과거 동기화 실패는 이력이며 실제 발행 검증을 대신하지 않습니다. 실제 모델 입력의 프롬프트까지 일치하는지 점검하며 불일치는 `CONFIG_SYNC_PENDING`으로 보류합니다. 현재 확인 범위와 남은 DB 이관·무인 저장 검증은 [STATE](docs/STATE.md)를 따릅니다.
2026-10-05 실계정 UI의 `9_이름의 유래`에서 카테고리 번호 9를 확인했습니다. 화요일용 실비김치 초안은 10월 5일 19:17 KST에 `SAVED_NAVER`로 확인했으며 10월 6일은 기존 초안의 편집 예약입니다. 실제 저장일을 10월 6일로 바꾸지 않습니다. 서식·대표이미지 세부 검증과 새 외부 예약 지침 등록은 저장 성공과 별도입니다.
실계정에서 육아·요리·투자 카테고리 번호와 SmartEditor 사진 첨부·임시저장 동작을 확인했습니다. 요리는 사용자 원본 사진만 사용하고, 육아·투자는 생성 이미지를 사용합니다.
10월 7일 햄버거 AI는 외부 확인으로 11:16 KST 임시저장 및 발행 글 `224433957929`가 확인됐으며 당일 합산 한도는 1/1입니다. 과거 임시 홀드 이력은 보존하고 이 문서 수정으로 저장소 영수증을 새로 만들지 않습니다.
ChatGPT의 새 대화·첨부 파일을 상시 읽는 연결은 없으며, 실제 질문·자료를 입력 파일로 등록해야 합니다. 10월 9일은 `owner-20261009-new-policy`의 수동 편집 홀드입니다. 승인된 KIS 정책 원본·근거가 없으면 계속 보류합니다. 알테오젠의 10월 6일 별도 수동 작업은 이 금요일 파이프라인 밖이며 기존 한도·영수증을 초기화하지 않습니다.

1. [DAILY_PLAN](docs/DAILY_PLAN.md)의 전환 확인과 [운영 가이드](docs/OPERATIONS.md)를 확인합니다.
2. [입력 가이드](docs/INPUTS.md)에 따라 실제 당일 질문·자료와 편집 하위유형을 등록합니다.
3. 외부 Work 지시문·실행 코드·당일 receipts를 확인한 뒤 승인된 경로에서 준비·저장을 검증합니다.
4. Windows 실행기·n8n·기존 GitHub 예약은 비활성 대안입니다. 예시 기본값 1은 활성화를 의미하지 않으며 현재 경로와 동시에 켜지 않습니다.
