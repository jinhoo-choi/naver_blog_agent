## 매 글 적용 순서

문체는 [VOICE](VOICE.md)의 `seonoo-voice-v1`을 적용한다. 템플릿의 글꼴·크기·색·구분선은 유지하고 실제 내용을 채울 때 도치·강조·유머를 선택한다. 장식을 위한 자리표시자나 모든 글에 복사하는 고정 농담은 만들지 않는다.

검증된 승인 양식 불러오기 → 내용·실제 미디어·관련 글감/카드 배치 → 주제에 맞는 소수 태그 선정 → 실제 임시저장 → 같은 저장본 PC/모바일360px 평가 → 결함 수정 → 동일 초안 저장·반영 확인 → 보고. 추가 재평가·반복 수정·발행으로 연장하지 않는다. 실제 발행은 소유자가 직접 한다. 수정본 저장 확인과 새 품질평가를 구분한다. 양식 때문에 새 글·유료 호출·공개 권한을 추가하지 않는다.

- 기능별 활용·확인 기준은 [RESET_DESIGN](RESET_DESIGN.md)의 ‘스마트에디터 기능 선택’을 따른다. 증권·뉴스·상품 등 지원 대상은 글감, 그 밖의 출처/서비스/관련 글은 URL 삽입 카드를 사용한다. 글감은 URL 카드와 동등한 네이티브 첨부이며 같은 대상을 둘 다 넣지 않는다.
- 카드·캡처는 관련 설명 옆에 두고 본문에서 의미를 해석한다. 하단은 필요한 참고자료·관련 글만 남기며 같은 카드/주소를 다시 나열하지 않는다. 제목 말줄임으로 중요한 기사명/모델이 가려지면 인접 본문에 정확한 식별 정보를 쓴다.
- 태그는 실제 주제·질문에 맞는 소수(보통3~5개)만 고른다. 정확히5개·generic 태그 복사·단어 변형으로 수를 채우지 않는다. 태그 수나 글감 사용을 상위노출/유입2배의 근거로 쓰지 않는다.
- tags는 기존 JSON 배열을 유지한다. 모델 body에 태그를 중복 나열하지 않고 Work가 네이티브 태그와 실제 주제를 대조한다. 부족한 태그 수를 맞추기 위한 추가 유료 호출을 하지 않는다.

- 직접 관련 있는 실제 공개 내 글1~2개만 선정한다. 정확한 개별 URL·소유자·공개 상태·본문을 확인하고 이어 읽을 이유를 짧게 쓴 뒤 네이버 링크 추가(URL 삽입) 카드로 넣는다. AI 영상→관련 제작법, 음식 유래→관련 음식/단어 유래, 운동→관련 부위/동작의 실제 접점을 확인한다. 임시저장·예약·삭제·미확인·무관한 글은 제외하며 적격 글이 없으면 구역을 생략한다.
- 카드 제목·대표 이미지·모바일 잘림·연결 대상을 검수한다. 일반 하이퍼링크를 네이버 카드 삽입 완료로 기록하지 않는다. 카드 생성 실패는 중복 삽입하지 말고 해당 단계의 미완료로 보고한다.
- 본문·소제목·캡션·실제 구분선·여백과 오래된 날짜/수치/URL, `[교체: …]` 등 자리표시자 잔존을 확인한다. 이미지/영상은 승인 원본과 대조하며 제공되지 않은 경험·반응·효과·실패·설정은 창작하지 않는다.
- 대표 이미지, 기존 AI 표시 기준, 카테고리, 공개 범위, 검색 허용, 예약 시각은 템플릿과 별개로 대조한다. 이번 요청은 이를 변경하는 권한이 아니다. 저장은 기존 영수증·한도·중복방지를 따르며 실제 발행은 소유자가 직접 한다.
- 권한 거절·인증·CAPTCHA·플랫폼 제한은 우회하지 않는다. 시험 템플릿을 실제 원고로 저장/발행하지 않으며 실물 검수 통과 전 완료로 표시하지 않는다.

수동 작성과 기존 임시저장 수정은 AUTOMATION의 수동 콘텐츠 작성 예외를 따른다. 기존 원고에 시험 양식을 덮어쓰지 않고 필요한 구역만 편집한다.
