- D0~D6(7일)·D0~D27(28일)은 같은 발행 경과일의 누적 성과를 보는 후행 평가이며 당일 검수·일일 피드백·실증에 따른 증량의 대기 조건이 아니다. KST달력 기준으로 정확한168/672시간이나 회복 보장 기한이 아니다. 최초 발행과 수정 코호트를 분리하고 집계 지연/누락은 미확인으로 둔다.
- 매일 블로그 전체 검색건수·전체유입과 제공되는 글별 검색건수·전체유입, 발행 경과일·데이터 기준일·관측시각·지표별 관측 글수/누락수를 기록한다. 당일 부분 통계와 전일 완료 통계를 분리하고 동일 경과일·주제 코호트의 검색건수 합계/글당평균/중앙값/0건 비율, 발견확인 비율(미확인별도), 글당전체유입을 비교한다. 전체 검색건수를 글수로 나누어 개별 글 실적으로 쓰거나 검색 비중×조회수로 검색 건수를 만들지 않는다. 주간 순방문자를 일별합으로 만들지 않는다.
- 비용은 실제 API/이미지/인력분·저장검수분·재작업분을 분리하고 원고별 시간과 평균/최댓값을 기록한다. 오류율은 핵심오류 원고수/검수원고수, 공개후정정률과 중복/불확실제출은 별도다. 통과율=적격고유원고/검수고유원고이며 재시도를 분모로 늘리지 않는다.
- 증량 시 두 축 비중/기존3유형/서식/관찰방법은 고정한다. 주제·질문 난도·신규/수정·계절/요일을 맞춰 비교한다. 개편초기 관측과 과거 혼합18편을 순수발행량 실험으로 부르지 않는다. 순차 증량으로28일창이 겹치면 인과 식별 한계를 기록한다.
- 총 검색유입과 글당유입이 함께 늘면 공동 개선, 총량만 증가·평균유지는 규모 확대, 총량↑/평균↓는 일부성과로 보고한다. 수치가 없으면 성공 판정을 하지 않는다.
- 준비/자료/용량 또는 실측이 부족하면 현 단계 유지, 부실원고로 빈 슬롯을 채우지 않는다. 중대 오류·중복·무승인 공개·불확실 제출이면 관련 작업을 즉시 보류/조사한다. 당일·익일·24/72시간 점검에서 확인된 품질·용량 문제는 즉시 보완하고 필요시 관련 작업량을 조정한다. 검색성과는 반복 관측·주제 수요·동일 경과일 자료·비용/오류를 함께 검토해 단계 조정 여부를 판단하며7일/28일 자료는 후행 재평가에 활용한다. 하루 저유입이나 검색 미발견만으로 발행량 축소·검색 회복 실패를 판정하지 않는다. 일시적 조회 실패만으로 전 운영을 영구 중단하지 않는다.
- 기존 일일 조회·집계·원장 기록은 유지한다. 최신 사용자 요청에 따라 일상 진행/정상 발송·변화 없는 정상 보고 알림은 생략하고, 중요한 결정/신규 장애 또는 사용자가 요청한 최종 보고만 전달한다. 계획·설정 적용·실제 성공을 구분한다.
