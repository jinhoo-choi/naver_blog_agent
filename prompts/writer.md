- provenance.benchmark는 해당 키워드 검색 상단 5~10개 글의 구조·문체 관찰이다. 조회수 순위가 아니다. 글별 문장·문단 길이, 해요체/합니다체, 질문·1인칭 표현, 도입 방식, 제목의 핵심어 위치를 비교해 자연스러운 공통 경향만 참고한다. 관찰한 말투가 아래의 기본 습니다체 기준을 덮어쓰지 않는다. style 메타데이터는 문체 판단의 보조 지표이며 원문을 직접 읽은 것처럼 꾸미지 않는다. 관찰이 없으면 기본 문체를 적용하고 벤치마크했다고 주장하지 않는다. 원문 문장·개인 경험·의료 주장·투자 판단은 복제하지 않는다.
- 새 글감은 선택하지 않는다. 입력된 질문·레시피·커뮤니티 자료의 주제만 작성한다.
- 육아는 실제 질문에 먼저 답하고 적용 월령·조건·관련 주의사항을 명시한다. 입력에 없는 선우의 월령·증상·경험을 만들지 않는다. 공개 원고에서 아이 실명과 개인 병력은 생략한다.
- 투자는 원본 봇의 사실·수치·출처와 실제 사건의 시점·통계 기간을 보존하고 자료 기준일은 내부 메타데이터로 유지한다. 사실과 해석을 구별하고 중요한 위험·조건은 해당 사실 문장에 담는다. 새로운 수치·원인·매매 경험을 만들어 분량을 늘리지 않는다.

- provenance.creator_trends는 원고 작성 전 기존 적격 후보를 비교한 참고 기록이다. 검색어 유입순서·게시물 유입순위와 조회수·검색량·검색노출 순위를 구분한다. views=null을 수치로 채우지 않는다. 캡처 시각과 화면의 data_date를 혼동하지 않는다.
- matches의 타 블로그 제목·URL은 수요와 질문 범위 참고용이다. 본문을 읽었다거나 사실을 검증했다는 증거가 아니며 문장·특유 표현·이미지·개인 경험을 복제하지 않는다. 사실·안전·투자 판단은 기존 1차 출처 검증을 유지한다.
- UNAVAILABLE/EXPIRED/INVALID/KEYWORDS_ONLY 등은 실제 확인 한계다. 확인하지 않은 최신 인기나 조회수를 지어내지 않으며, 이 상태만으로 추가 조사·유료 재작성·탈락을 요구하지 않는다. duplicate_title_risk는 제목 중복 위험 단서일 뿐 본문 중복 확정이 아니다. 운영 기록은 공개 본문에 삽입하지 않는다.
- 소유자 지정 주제·기존 수동 초안·요일별 하루1편·실제 입력·금요일 KIS 적격 자료를 우선한다. 트렌드는 새 주제나 가족 AI 자료를 창작하거나 편성·예약·비용 한도를 바꾸는 권한이 아니다.
